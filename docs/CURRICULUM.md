# Curriculum & Modules

DataDojo content is organized as **modules** — self-contained course packs. The platform
discovers modules from `content/`, shows them in the course catalog, and enforces
prerequisites. Each module declares its own sandbox image and libraries, which is also what
drives IntelliSense and the Library Explorer.

```
Python Basics ──► Data Science ──► AI
      │                │            │
      ├────────────────┴────────────┴──► Projects (build plans)
      └──► Data Structures & Algorithms

Later: Docker · Kubernetes · MLOps
```

## Starter modules

| 6 | Lists & tuples | shopping list |
| 7 | Dictionaries & sets | word counter |

standard library instead.

synthetic and generated by `scripts/make_datasets.py`.

Capstone (guided end-to-end EDA + model report) lives in the Projects module.

### 3. AI — `ai`
Prereq: Python Basics (Data Science recommended). Image: `dojo-ds` (no PyTorch: NumPy
and scikit-learn teach the same ideas). Model backend, chosen by the learner and always
visible: local Ollama or Claude with their own API key, through `dojo_ai`. Exercises are
graded with a practice model, never a real one. `/data/handbook/` is a small fictional
company handbook for the RAG lessons.

| # | Lesson | Hands-on |
|---|---|---|
| 1 | Meet the model: ML vs deep learning vs LLMs, first `chat` | explain simply, summarise reviews |
| 2 | A neuron from scratch (NumPy) | build a neuron, teach it AND |
| 3 | How models learn: loss and gradient descent | MSE, gradient descent |
| 4 | Neural networks in practice (scikit-learn) | digit classifier, layer size |
| 5 | How LLMs work: tokens, context, temperature | token/cost estimate, fit the context |
| 6 | Conversations and memory | build messages, chatbot class |
| 7 | Prompting and structured output | few-shot prompt, JSON extraction with retry |
| 8 | Embeddings and semantic search | cosine similarity, semantic search |
| 9 | RAG: answer from your documents | chunking, answer from the handbook |
| 10 | Tools and agents | run a tool safely, the agent loop |
| 11 | Evaluating AI output | exact match, keyword eval |
| 12 | Responsible AI: privacy, bias, safety | redact PII, a safer chat function |

Capstone (document Q&A assistant with evals) lives in the Projects module.

### 4. Projects — `projects`
Build plans that combine modules. Each plan has a brief, checkpoints (graded by tests
that also re-check earlier checkpoints), and three levels the learner can switch
between: **Guided** (TODO skeleton, hints, show me), **Assisted** (function outlines,
hints), **Solo** (own code carried forward, no hints). Finished projects appear in the
learner's portfolio and download as a zip with a README.

| Project | Uses | View | Checkpoints |
|---|---|---|---|
| Expense Tracker | Python Basics | editor | add & list → totals → save/load JSON → command loop |
| Weather Dashboard | Data Science | notebook | load & clean → monthly summary → chart → HTML report |
| House Price Report (DS capstone) | Data Science | notebook | explore → baseline vs model → features → written report |
| Movie Recommender | Data Science | notebook | vectors → similarity → recommend → genre precision |
| Document Q&A Bot (AI capstone) | AI | notebook + AI picker | load & chunk → retrieve → answer with sources → eval |
| Digit Classifier | AI | notebook | split → baseline → train → mistakes & predict |

Authoring: put a `project:` block in `lesson.yaml` (`brief`, `uses`, optional `view` and
`ai`); each checkpoint folder has `starter.py` (Guided), `starter.assisted.py` and
`starter.solo.py` (used only when the learner has no passing code from the previous
checkpoint). `dojo validate` checks that every starter variant fails and the solution
passes.

### 5. Data Structures & Algorithms — `dsa`
Audience: finished Python Basics. Image: `dojo-python`. Lessons start with **showcases**
(animated, step-through, with your own input) and exercises include **speed tests**
(`assert_fast`) on inputs of 50k–1M items, with Big-O advice when code is too slow.

| # | Lesson | Showcases | Exercises |
|---|---|---|---|
| 1 | Big-O | linear vs binary search | contains duplicate, most frequent |
| 2 | Two pointers | two pointers | palindrome, pair with sum |
| 3 | Hashing | | group anagrams, two sum |
| 4 | Stacks and queues | bracket stack | balanced brackets, RPN calculator |
| 5 | Recursion | Fibonacci call tree | flatten, memoised Fibonacci |
| 6 | Sorting | bubble, insertion, merge sort | insertion sort, merge sort (no `sorted()`) |
| 7 | Binary search | binary search | binary search, first value ≥ target (no `bisect`) |
| 8 | Trees and BSTs | BST insert | height and size, build a BST |
| 9 | Heaps | min-heap push/pop | k smallest, merge many sorted lists |
| 10 | Graphs | BFS, DFS | fewest hops, count islands |
| 11 | Shortest paths | Dijkstra | distances, cheapest route |
| 12 | Dynamic programming | coin-change table | fewest coins, ways to make change |

## Module format

```
content/
  python-basics/
    module.yaml
    01-first-program/
      lesson.yaml          # ordered guided steps (see below)
      ex01-hello/
        exercise.yaml
        starter.py
        solution.py        # reference — never sent to the browser
        tests/
          test_visible.py  # learner can run these
          test_hidden.py   # grading, edge cases
```

`module.yaml`:

```yaml
id: data-science
title: Data Science
level: beginner-intermediate
prerequisites: [python-basics]
sandbox:
  image: dojo-ds
  packages: [numpy, pandas, matplotlib, seaborn, plotly, scipy, scikit-learn, sqlalchemy]
  services: [postgres]        # optional per-session sidecars
  network: none               # or an allowlist (AI module)
default_view: notebook        # editor | notebook
library_explorer:             # what the explorer panel highlights first
  featured: [pandas, numpy, matplotlib.pyplot]
lessons: [01-intro, 02-numpy, 03-pandas]
```

`lesson.yaml` (guided steps):

```yaml
title: Lists
steps:
  - type: explain
    md: "A list holds many values in order..."
  - type: example
    code: "fruits = ['apple', 'banana']\nprint(fruits[0])"
    runnable: true
  - type: try-it              # small typed step, checked instantly
    prompt: "Add 'cherry' to fruits using .append()"
    check: "assert fruits[-1] == 'cherry'"
    hints: ["Lists have an append method", "fruits.append('cherry')"]
  - type: exercise
    ref: ex01-shopping-list
  - type: quiz
    question: "What does fruits[-1] return?"
    options: [first item, last item, an error]
    answer: 1
```
